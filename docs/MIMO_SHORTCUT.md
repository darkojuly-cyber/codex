# Mimo 桌面图标与启动热键

## 只需创建一次

1. 把聊天中提供的 Mimo 图片保存为 PNG（也支持 JPG/BMP/ICO）到电脑任意位置。
2. 更新项目源码，保留原有配置和数据。
3. 在与 `package.json`、`Start.cmd` 同一层的目录双击 **CreateShortcut.cmd**。
4. 出现图片选择框时，选中保存的 Mimo 图片。
5. 桌面会创建 **Mimo - EvoMeme**，热键为 **Ctrl + Alt + M**。

以后双击 Mimo 图标，或按 Ctrl + Alt + M，即可调用既有一键启动功能。创建快捷方式本身不会启动服务；已有一键会话时使用快捷方式不会再启动第二套服务。

## 图片和文件

- 图片仅在本机转换成带 16/32/48/256px 四个尺寸的 Windows ICO，保留完整画面和原背景，不裁剪或重绘。
- 图标保存在项目的 `.data/launcher/mimo.ico`，源码更新时保留 `.data` 即可；原始图片随后移动不影响已生成图标。
- 支持实际桌面路径，包括中文用户名、中文目录和 OneDrive 重定向桌面。目标直接指向原项目 `Start.cmd`，工作目录为项目根目录。
- 如果已在根目录保存 `mimo.png`、`assets/mimo.png` 或已有生成的图标，工具可直接使用；否则弹出选择框。取消选择时不会创建快捷方式。
- 同名快捷方式指向其他位置时会提示，不覆盖它。移动项目后，先删除桌面的旧 Mimo 快捷方式，再在新项目位置运行创建工具。

## 修改或移除热键

右键桌面 **Mimo - EvoMeme → 属性 → 快捷方式 → 快捷键**，可以改为其他组合键。如与其他软件冲突，在这里更换即可。

删除桌面的 `.lnk` 快捷方式即可移除这项快捷键，不影响项目文件、配置、后台服务或其他软件快捷键。不要把 Start.cmd 文件本体移到桌面。

仍使用原来的 `Stop.cmd` 停止服务、`Status.cmd` 查看状态；控制窗口可以最小化。若希望 Windows 登录后自启，可将这个快捷方式的副本放入 `Win+R → shell:startup` 打开的文件夹。

## 验证范围

通过 lint、构建和 80 项本地测试；ICO 文件还经独立图像解码器验证，四个尺寸及像素颜色正确。Windows 专属的图片选择框、COM 快捷方式、桌面热键注册需在用户电脑运行一次确认。创建工具不修改 Windows 执行策略，不要求管理员权限，也不安装后台键盘监听程序。

用户这次图片只在聊天中可见，工作区没有可读取的原始文件，因此没有把替代图案或重绘图冒充原图打包到源码。运行工具时选择用户保存的原图即可。
