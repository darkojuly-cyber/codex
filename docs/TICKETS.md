# 工单配置与操作

## Windows 更新

1. 双击 `Stop.cmd` 停止本项目；不关闭其他工作，也不需要重启电脑。
2. 将 `evomeme-v0.1` 分支新版文件放到项目根目录，保留本机 `.env.local`、`.env`、`.data`。不要再次解压成嵌套的同名项目目录。
3. 双击新增的 `RegisterCommands.cmd`，注册 `/ticket-panel` 等命令；完成后关闭该窗口。
4. 双击 `Start.cmd`。现有启动器会构建变化的源码并启动服务，数据库启动时自动迁移。本次没有新增 npm 依赖；若项目缺少依赖，先在项目目录运行 `npm ci`。已有 Mimo 快捷方式继续使用。

## 启用与公开入口

后台「设置」填写工单分类 ID 和 help-desk 频道 ID，勾选启用工单，保存草稿；在「运营阶段」检查并发布该配置。help-desk 是普通成员可见的公开入口；工单分类是运营批准用于创建私密频道的分类。仅保存草稿不会生效，不会自动创建分类或角色。

管理员/社区经理到配置的 help-desk 运行 `/ticket-panel`，发布带「Submit a Ticket」按钮的常驻卡片，可以手动置顶。再次运行会更新已记录的同一面板，而不是不断刷屏。机器人不会覆盖其他人的消息。只有核对旧面板已删除或未知投递结果之后，才用 `replace:true` 显式新建。

成员也可通过 `/ticket` 或欢迎卡中的工单按钮进入。选择 Bug、Creation Help、Account、Feature Request、Event 或 Other 后，填写摘要、描述和可选设备/版本，再进入专属频道补充截图或视频。不要在表单提交密码、Token 或支付资料。

API、Bot、Worker 都需要保持运行；Caddy 提供本机后台 HTTPS。工单权限与通知通过 Worker 异步同步，查看后台同步状态及回复回执；关闭浏览器不会停止队列。

## 工作人员处理

后台「工单」提供状态、优先级、主题、成员、处理人和编号/摘要筛选，每页 20 条。点击工单编号打开详情弹窗，查看私密频道链接、处理记录、分配人和同步状态。内部记录也每页 20 条，避免无限向下滚动。多人同时编辑会检测版本冲突，刷新后再操作。

- **接单**：将未分配工单分给自己并进入调查中。其他人员已接单时不会被一键抢走；有权限的工作人员可以填写处理人 Discord 用户 ID 调整分配。
- **状态**：开放 → 调查中 → 等待用户 → 已解决 → 已关闭，可按实际情况调整。状态变化排队发送简短通知，过时通知会取消。
- **内部备注**：保存在后台，仅授权工作人员可见，绝不作为用户通知或状态卡正文。
- **回复申请人**：独立输入框，确认后排队发到该工单的私密频道。最近 10 条回复有投递回执；`SENT` 表示 Discord 已接受，不表示用户已读。完整对话仍在 Discord 中查看。
- **关闭/重开**：关闭后，申请人的发言、附件、反应及开线程权限被关闭，可继续查看历史。同步成功后才视为权限已更新；重开恢复发言。默认允许 7 天内重开，最多 2 张活跃工单、每小时 5 次新建，均从已发布配置读取。重复关闭不会延长重开窗口。
- **问题积分**：管理员/社区经理人工确认 Bug 或 Feature Request 有效且唯一后，以内部备注为审核理由发放已发布规则中的问题积分。同一工单只发一次；不因提交或关闭工单自动发分。工单频道及其子线程不计聊天积分。

频道中的「Staff actions」也提供接单、调查中、等待用户、已解决操作。成员可用「Close ticket」确认关闭，以及在窗口期内「Reopen ticket」。

## 私密权限与异常

`STAFF_ROLE_IDS`、`MODERATOR_ROLE_IDS` 和超级管理员白名单是整体工单处理人员。`SUPPORT_ROLE_IDS` 本身不授予所有私密频道的访问权；Support 仅能在后台查看自己创建或被分配的工单，分配同步后获得对应频道权限，转交后撤销对应个人授权。真实处理人必须是本公会授权工作人员。Discord 的服务器所有者/Administrator 权限本身可以绕过频道限制。

不会公开降级建单、自动公开工单，也不会把内部备注写入公共频道。回复不主动 ping 任何成员。附件留在 Discord，此版本不备份完整聊天、下载附件或自动删除关闭频道。

权限/卡片同步是幂等更新，可以有限重试；失败后后台可点重试同步。同步完成前暂停该工单的排队回复，避免转交过程中仍向旧权限范围发送新内容。发送回复或创建频道遇到超时等结果不确定的情况，标记 `UNKNOWN`，不自动重发或重建。工作人员先核查实际频道/消息，避免重复。管理员可以记录核查理由，关闭失败/未知的建单记录；已有频道需自行核实处理，不会被该按钮自动删除。未知面板也需要人工检查后显式替换。

云端自动测试使用 Mock/PGlite 与模拟 Discord HTTP，覆盖完整流程和权限隔离，不能替代真实 Guild 权限验收。首次启用后用普通成员账号提交一张测试工单，验证面板、成员可见范围、分配、回复、关闭只读与重开。
